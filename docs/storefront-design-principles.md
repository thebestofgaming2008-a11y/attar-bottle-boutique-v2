# BADR storefront UI direction

Owner direction, 6 September 2026:

- Use established mobile-first retail interfaces as the reference before adding UI. Research current Shopify theme/store examples such as Prestige and Gymshark, and match their relevant interaction/layout patterns using BADR branding. Do not claim measured conversion improvements without evidence or copy proprietary theme source/assets without permission.
- Keep customer copy short. Prefer whitespace, clear typography and a single obvious next action to explanatory cards, badges, repeated instructions and multiple competing buttons.
- Coupon entry should be a compact input and Apply button. Show validation/savings when relevant, not a permanent paragraph of offer rules.
- Checkout should use a clear form hierarchy, generous field spacing, readable mobile input text and an easy-to-find order summary. Preserve accessible labels, useful validation, payment-recovery warnings and security controls.
- Admin should expose one task per destination. Bundles, Coupons and Announcement bar are separate. Put optional settings under More options, keep Save draft and Publish distinct, and never publish unrelated drafts.
- Check mobile and desktop visually, not only through a successful build. Preserve existing prices, promotions, stock and payments during presentation work.

References inspected: https://www.gymshark.com/cart and https://prestige-theme-couture.myshopify.com/ (theme: https://themes.shopify.com/themes/prestige/presets/prestige).
